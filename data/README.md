## Dataset from Motoya, 60 instances with up to 40 customer nodes and 8 battery swap stations.

## Name explanation
According to Montoya et al., cases are named using the following convention: tcAcBsCcDE, where: 
- A is the method used to place the customers (i.e., 0: random uniform, 1: clustered, 2: mixture of both). 
- B is the number of customers. 
- C is the number of the battery swap stations. 
- D is 't' if the battery swap stations are located using a p-median heuristic and 'f' if the battery swap stations were randomly located. 
- E is the number of the instance for each combination of parameters (i.e., E={0,1,2,3,4}).

## Note
This dataset was used for Segmented Charging Vehicle Routing Problem by Montoya, we only use the location data of depot, customer nodes and charge stations (battery swap station in our paper) to fit our problem.
